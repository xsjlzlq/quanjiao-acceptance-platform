# 全椒县第二轮土地承包到期后再延长30年试点工作县级验收管理平台

## 项目简介

**全椒县县级验收管理平台**是专为全椒县第二轮土地承包到期后再延长30年试点工作量身定制的数字化全流程验收管理系统。平台依据《全椒县第二轮土地承包到期后再延长30年试点工作县级自查工作方案》标准规范设计开发，采用现代化 Web/H5 架构，支持移动端（手机/Pad）与桌面端无缝协同作业。

系统全面打通了**自查申请受理、抽样管理、内业核查填报、外业现场勘验、电子签名、佐证上传、得分自动汇总、验收等级评定、自查中止判定、整改通知下发与销号台账管理**的业务闭环，并深度集成了基于 Windows COM 技术的原版 Word 报表无损导出能力，实现了《方案》全部 13 类附件表单的自动化生成。

## 核心业务功能

### 1. 工作台与全局监控看板
- **自查进度全览**：直观展示全县各乡镇自查申请受理、自查进行中、整改中、自查完成等状态。
- **抽样与核查统计**：实时统计各乡镇及发包方抽样数量、承包户抽检数，内置红线规则强校验提示。
- **得分与等级概览**：动态汇总各乡镇内业得分、外业得分与综合得分，呈现验收等级分布。
- **角色专属待办与快捷入口**：按管理员、专家组、内业组、外业组、乡镇角色智能推送待办事项。

### 2. 自查任务与智能抽样管理
- **权属层级联动**：全县乡镇、行政村、村民小组、承包方层级数据联动检索。
- **抽样规则合规校验**：
  - 每个乡镇抽取 2～5 个发包方（村民组）；
  - 每个发包方抽取 5% 的承包农户；
  - 全县抽样发包方总数严格要求大于 20 个（不足自动拦截并预警）。
- **多种抽样模式**：支持按规则随机抽样、批量导入 Excel 抽样清单以及抽样数据一键重置。
- **表单导出**：一键生成并导出《附件4 成果检查验收申请表》与《附件5 自查抽样统计表》。

### 3. 内业核查数字化填报
完整复刻并精细化支持方案中内业 4 大维度的检查录入与自动打分（内业满分 70 分）：
1. **表 1/4 机制运行（满分 15 分）**：工作专班、实施方案、宣传动员、政策培训、经费与技术保障等。
2. **表 2/4 程序规范（满分 30 分）**：摸底调查、方案形成与表决、公示审核、合同签订、证书发放到户、网签入库等。
3. **表 3/4 政策落实（满分 15 分）**：大稳定小调整、消亡户处置、妇女等特殊群体权益保障、新增人口保障等。
4. **表 4/4 工作成效（满分 10 分）**：矛盾纠纷化解、群众满意度、档案归档规范化、信息化成果质量等。
- **自动化计算**：支持扣分项自动累加与分值折算，自动生成并导出《附件6 县级自查内业组检查记录表》（按乡镇/按全县）及《附件7 县级自查内业组检查得分表》。

### 4. 外业现场移动勘验与核查
专为外业现场核验作业设计（外业满分 30 分）：
- **农户与地块核查**：现场核对承包方身份、承包地块编码、实测面积、四至边界及空间权属。
- **家庭成员与权益核验**：现场比对家庭成员信息及增减变动情况。
- **群众满意度测评**：现场记录承包方对延包工作的满意度评价（满意/基本满意/不满意）。
- **电子手写签名**：集成 HTML5 Canvas 电子签名画板，支持农户与核查人员现场手写签名与图片上传。
- **现场佐证材料拍照上传**：支持地块勘验、入户核查等照片现场上传与存储。
- **表单导出**：自动计算程序规范得分与满意度得分，一键导出《附件8 外业核查记录表》与《附件9 县级自查外业组检查得分表》。

### 5. 得分汇总与验收评定
- **多源得分自动聚合**：
  $$\text{综合得分 (100分)} = \text{机制运行 (15分)} + \text{程序规范 (50分)} + \text{政策落实 (15分)} + \text{工作成效 (20分)}$$
  其中程序规范 = 内业 30 分 + 外业 20 分；工作成效 = 内业 10 分 + 外业满意度 10 分。
- **特殊情形扣分**：支持对重大违规、严重遗留问题等特殊情形直接进行总分核减。
- **评定等级自动判定**：
  - **优秀**：$\ge 90$ 分（验收评定为合格）
  - **良好**：$80 \sim 89$ 分（验收评定为合格）
  - **合格**：$70 \sim 79$ 分（验收评定为合格）
  - **不合格**：$< 70$ 分（验收评定为不合格）
- **自查中止机制**：支持记录材料造假、重大纠纷未化解等中止情形并输出专家书面意见。
- **表单导出**：一键导出《附件10 县级自查得分汇总表》与《附件11 县级自查验收评定表》。

### 6. 问题整改与销号闭环管理
- **问题智能归集**：自动提取内业与外业填报中发现的全部问题项。
- **通知书与销号台账**：支持按乡镇快速生成《附件12 整改通知书》与《附件13 问题整改销号台账》，支持整改跟踪与闭环销号。

### 7. 系统管理与空间数据导入
- **多角色权限控制**：基于角色的权限管理（RBAC）结合 20+ 项细粒度功能权限开关。
- **用户管理与安全**：支持用户创建、密码重置、登录 Token 鉴权（HMAC-SHA256）。
- **空间与权属数据一键入库**：支持解析并导入 Access 权属数据库（`.mdb`）、Shapefile 矢量属性数据（`.shp`）与权属单位代码表（`.xls`）。

## 技术架构

```
┌───────────────────────────────────────────────────────────┐
│                    Vue 3 + Vant 4 前端                     │
│  (工作台 / 抽样任务 / 内外业表单 / 得分看板 / 整改台账 / 系统设置) │
└─────────────────────────────┬─────────────────────────────┘
                              │ HTTP / RESTful API (JSON)
┌─────────────────────────────▼─────────────────────────────┐
│                    FastAPI 异步后端服务                    │
│  (路由调度 / 数据校验 / 权限拦截 / 抽样算法 / 评分引擎)        │
└──────────────┬──────────────────────────────┬─────────────┘
               │                              │
┌──────────────▼──────────────┐┌──────────────▼─────────────┐
│    PostgreSQL + PostGIS     ││   Windows COM 原生导出引擎  │
│ (业务数据/空间属性/填报记录) ││ (win32com / Word 原生模板) │
└─────────────────────────────┘└────────────────────────────┘
```

### 技术栈选型
- **后端框架**：Python 3.13 + FastAPI + Uvicorn
- **ORM & 数据库**：SQLAlchemy (Async/Sync) + asyncpg + psycopg2 + PostgreSQL
- **地理空间与数据分析**：GeoPandas + Pandas + pyodbc + openpyxl + xlrd
- **文档渲染与导出**：`pywin32` (`win32com.client`) + `pythoncom`（保证原版 Word 格式、表格行高、下划线、复选框 ☑/□ 完全精确还原）
- **前端框架**：Vue 3 (Composition API, `<script setup>`) + Vite 4
- **UI 组件库**：Vant 4（针对移动端与桌面端自适应定制）
- **路由与状态管理**：Vue Router 4 + Pinia 2
- **网络通信**：Axios (支持请求/响应拦截与 Token 认证)

## 快速上手与部署运行

### 1. 环境准备
- **操作系统**：Windows 10 / Windows 11 / Windows Server（Word COM 自动化导出需要 Windows 环境并安装 Microsoft Office Word）
- **Python**：Python 3.10+（推荐 Python 3.11 或 3.13）
- **Node.js**：Node.js 18+ 与 npm
- **数据库**：PostgreSQL 14+（需提前创建数据库 `quanjiao`）

### 2. 数据库配置
在 PostgreSQL 中创建数据库：
```sql
CREATE DATABASE quanjiao;
```
若需修改数据库连接串，请在环境变量或 `backend/database.py` 中配置 `DATABASE_URL`：
```python
DATABASE_URL = "postgresql+asyncpg://postgres:123456@localhost:5432/quanjiao"
```

### 3. 后端服务启动
1. 进入后端目录并安装 Python 依赖：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```
2. 导入初始基础数据（如已有 MDB/SHP 权属数据）：
   ```bash
   python data_importer.py
   ```
3. 启动 FastAPI 后端服务：
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8081 --reload
   ```
   后端服务启动后，接口文档可直接访问：`http://localhost:8081/docs`

### 4. 前端服务启动
1. 进入前端目录并安装 Node 依赖：
   ```bash
   cd frontend
   npm install
   ```
2. 启动 Vite 开发服务器：
   ```bash
   npm run dev
   ```
3. 浏览器访问前端页面：`http://localhost:3000`

### 5. 默认管理员账号
- **用户名**：`admin`
- **默认密码**：`admin123`

## 生产部署与维护说明

1. **前端生产打包**：
   ```bash
   cd frontend
   npm run build
   ```
   打包产物将输出至 `frontend/dist` 目录，可通过 Nginx 进行静态资源代理。

2. **Word COM 进程维护**：
   - 导出引擎在每次文档生成后均严格执行 `doc.Close(False)` 与 `word_app.Quit()`，并配合 `pythoncom.CoInitialize()` / `CoUninitialize()` 管理 COM 生命周期，保证高并发导出下的系统稳定性。
   - 导出生成的文档统一保存在 `backend/downloads/` 目录下，支持前端随时下载。

3. **权限全景**：
   系统支持对 6 大模块的细粒度权限控制，支持管理员在【系统设置】中针对不同人员开启或禁用独立操作项（如仅填报、仅查看、仅导出对应表单等）。
